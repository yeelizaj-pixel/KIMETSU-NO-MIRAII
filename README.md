# Kimetsu no Mirai

## Sobre el proyecto

Este proyecto corresponde a mi portafolio web personal como estudiante de Ingeniería en Sistemas.

El diseño está inspirado en el universo de Demon Slayer: Kimetsu no Yaiba, utilizando una combinación de elementos visuales elegantes, colores suaves y una estructura moderna.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Secciones del proyecto

- Inicio
- Proyectos
- Blog

## Objetivo

Mostrar parte de mi proceso de aprendizaje y los conocimientos que voy adquiriendo durante mi formación universitaria.
