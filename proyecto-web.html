PROYECTO 01 · DESARROLLO WEB

Mi primer proyecto web

Este proyecto representa una de mis primeras experiencias creando una página web desde cero y descubriendo cómo una idea puede convertirse en una interfaz utilizando código.

Sobre el proyecto

El objetivo principal fue aprender a organizar una página web utilizando HTML para construir su estructura y CSS para trabajar su apariencia visual.

Lo que aprendí

Aprendí que desarrollar una página no consiste solamente en escribir código. También es necesario pensar en la organización, los colores, la distribución de los elementos y la experiencia de quien visita el sitio.
